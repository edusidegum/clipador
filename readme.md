# Clipador — Manual Operacional de Clipping Autorizado

Landing page estática (GitHub Pages) do produto digital **Manual Operacional de Clipping Autorizado** — Edição 2026.

## Sobre

Página institucional de divulgação do manual em PDF que estrutura uma operação de
clipping autorizado e distribuição de vídeos verticais (Reels, Shorts e TikTok):
mineração, edição, revisão, publicação, métricas e viabilidade financeira.

## Stack

- GitHub Pages (estático)
- HTML semântico (pt-BR)
- Schema.org: `Book`, `Product`, `FAQPage`
- Open Graph + Twitter Cards
- `robots.txt` + `sitemap.xml` + `canonical` explícito
- Checkout externo: Hotmart
